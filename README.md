## Featured projects

### [CBOW Word2Vec — From Scratch with NumPy](https://github.com/MathewShuvarikov/cbow-from-scratch)

An implementation of the **Continuous Bag-of-Words** model using NumPy, without deep-learning frameworks or automatic differentiation.

- Implemented forward propagation and **manual backpropagation** for both weight matrices.
- Verified the analytical derivatives using **finite-difference gradient checks** and automated `pytest` tests.
- Added numerically stable cross-entropy, reproducible SGD, and a command-line training and evaluation workflow.
- Trained and explored embeddings on *Alice's Adventures in Wonderland* using cosine similarity and PCA.

**Technologies:** Python · NumPy · pytest · Matplotlib · scikit-learn · GitHub Actions

### [Housing Price Prediction — Web Application](https://github.com/MathewShuvarikov/pabd24)
